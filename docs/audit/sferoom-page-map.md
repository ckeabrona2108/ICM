## 19. Предварительная карта соответствия с нашим `/feed`

Ниже только структурное сравнение, не итоговый аудит.

Совпадает концептуально:

- публичная лента;
- вкладки `Все / Подписки`;
- feed filters;
- карточки с реакциями;
- отдельная страница публикации;
- публичное чтение и auth-gating для интеракций.

Отличается:

- у нас реакции визуально есть, но серверно пока бинарные;
- у нас comments UX заметно проще;
- у нас правый rail более редакционный и менее social;
- у нас нет доказанной модели reply-thread уровня SFEROOM;
- у нас нет подтверждённой rich action menu.

## 20. Что нужно для полного закрытия page map
